corenote

v0.1.0 MIT · SQLite · macOS

Fast command-line interface to your local Apple Notes database via direct read-safe SQLite access — search, inspect, and pipe notes straight from your terminal.

$brew install AungMyoKyaw/homebrew-tap/corenote

Quick Start

macOS Terminal
$ corenote list# List recent Apple Notes
$ corenote search "architecture"# Full-text search across notes
$ corenote show <id># Print a note body to stdout
$ corenote --help# Full subcommand reference

Capabilities

  • Direct local SQLite access to Apple Notes store
  • Fast offline search without opening Notes.app
  • Clean plain-text output for grep, jq, and scripts
  • Automatic quarantine removal during brew install

Permissions & Troubleshooting

macOS requires Full Disk Access for your terminal app to read the local Apple Notes SQLite database (System Settings → Privacy & Security → Full Disk Access).

If macOS still flags the binary:
xattr -d com.apple.quarantine "$(brew --prefix)/bin/corenote"
