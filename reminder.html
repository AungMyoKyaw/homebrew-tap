reminder

A full command-line interface to Apple Reminders. Reads and writes through EventKit so the data stays in sync with the system app on every other device.

Features

Your reminders, on your terms.

Native EventKit integration

Writes go straight to Apple Reminders. No middleman, no sync delay, no proprietary format.

Full create, edit, complete

Add, modify, mark complete, and delete reminders from the shell. Every field EventKit exposes.

Smart lists and filters

Search by date, list, priority, or completion. Build filters the same way you build shell pipelines.

Scriptable and composable

Drive reminders from launchd, cron, or your editor's build hook. Pipe results into other tools.

Usage

From install to first reminder in one terminal.

~ zsh reminder 3.0.4
$ brew install AungMyoKyaw/homebrew-tap/reminder $ reminder add --list Today --due "in 2 hours" "Submit PR review" ✓ added to Today · due 16:30 $ reminder list --today · 16:30 Submit PR review · 18:00 Pick up groceries $ reminder complete --id 42 ✓ completed: Submit PR review
