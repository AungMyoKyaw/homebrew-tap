reminder

v3.0.4 MIT · Swift · EventKit

Native macOS command-line interface for Apple Reminders with full EventKit integration, instant execution, and zero external runtime dependencies.

$brew install AungMyoKyaw/homebrew-tap/reminder

Quick Start

macOS Terminal
$ reminder list# List upcoming reminders
$ reminder add "Ship homebrew-tap"# Create a reminder in default list
$ reminder complete 1# Mark item #1 complete
$ reminder --help# Full subcommand reference

Capabilities

  • Direct EventKit sync with iCloud & Apple Reminders
  • Native compiled Swift binary — sub-20ms startup
  • Scriptable plain-text output for shell pipelines
  • Automatic quarantine removal during brew install

Permissions & Troubleshooting

On first run, macOS prompts Terminal for Reminders access — choose Allow.

If macOS still flags the binary:
xattr -d com.apple.quarantine "$(brew --prefix)/bin/reminder"
